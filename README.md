# GigaChat Agents

Локальная основа Windows-приложения на Electron, React и TypeScript. GigaChat API пока не подключён: сообщения сохраняются в локальной истории, но не отправляются модели.

## Требования

- Node.js 22.x
- npm 10.x

## Команды

```powershell
npm install
npm start
npm test
npx tsc --noEmit
npm run package
npx tsx scripts/seed-test-profile.ts
```

`npm start` запускает приложение для разработки. `npm run package` создаёт запускаемую сборку в `out/`, не устанавливая её в систему. Команда `seed-test-profile.ts` создаёт только в игнорируемой `.qa/profile` помеченный тестовый диалог с примером ответа и файлами Markdown/PDF. Для его просмотра запустите EXE с `--user-data-dir="<полный путь к app/.qa/profile>"`; обычный профиль остаётся пустым.

## Локальные данные

Настройки, чаты, проекты, черновики и инструкции хранятся в каталоге Electron `app.getPath('userData')` — в Windows внутри `%APPDATA%\GigaChat Agents`. Каждый чат имеет устойчивый ID и свой каталог `chats/<uuid>/`: в `chat.json` находятся название, проект, состояние архива и закрепления, черновик, сообщения и перечень файлов; сами копии файлов находятся в `files/`. Старый `chats.json` версий 1–2 переносится один раз, сохраняется без изменений и копируется в `chats.json.bak`. `GIGACHAT.md` и проектные `AGENTS.md` остаются в данных приложения и не записываются в выбранные рабочие папки. Секреты не хранятся.

До подключения API работают локальные чаты, сообщения пользователя, вложения, проекты, архив, выбор папки и программы открытия, инструкции, а также темы Изумрудная / Тёмная / Светлая / Тёплая и режим «Как в Windows». Изумрудная — тема новой установки; прежняя сохранённая «Тёмная» переносится в «Изумрудную» без изменения вида. Режим Windows использует нейтральную тёмную тему при тёмном оформлении системы. Темы, переключатели и инструкции сохраняются автоматически; при ошибке записи введённый текст остаётся в редакторе. Сообщение и очистка его черновика записываются вместе. Выбранный файл копируется в каталог чата; исходник не меняется, архив сохраняет копии, подтверждённое удаление чата убирает только копии. Настройки занимают всю рабочую область. На остальных экранах панель можно полностью скрыть, временно показать наведением на кнопку и закрепить нажатием. Окно запускается размером до 960×720 с масштабом содержимого 80%; Ctrl+`+` / Ctrl+`−` меняют масштаб, Ctrl+`0` возвращает 100%. При узкой области навигация открывается поверх основного экрана. Нативные кнопки окна сохраняют размер.

Переключатель вверху боковой панели показывает GigaChat API или GigaChat Web только в текущем сеансе. Подключение Web появится позже; выбор пока не меняет возможности приложения. Значок окна и сборки создан из круглой части `src/assets/gigachat-logo.png` без внешнего квадратного свечения и без изменения формы логотипа.

Меню действий чатов и проектов открываются на непрозрачной поверхности поверх основной области. Список для «Переместить в проект» открывается сбоку после 0,5 секунды наведения или сразу по нажатию; если проектов нет, показывает «Нету проектов». Создание, переименование и удаление используют диалоги внутри окна. Успешные уведомления исчезают через две секунды; ошибки закрываются вручную. Настройки открываются шестерёнкой у локального профиля, возврат — кнопкой «Назад»; верхние кнопки справки и настроек удалены. Копирование разрешено в сообщениях, полях ввода, редакторах и путях.

Сообщения не отправляются. В обычном профиле ответов модели нет. Данные моделей, разрешений, инструментов, голоса и API показываются как недоступные; изображение сохраняется как локальный чат, видео и подкасты отмечены как будущие функции.
