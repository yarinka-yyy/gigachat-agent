# GigaChat Agents

Локальная основа Windows-приложения на Electron, React и TypeScript. GigaChat API пока не подключён: сообщения остаются черновиками и не отправляются.

## Требования

- Node.js 22.x
- npm 10.x

## Команды

```powershell
npm install
npm start
npm test
npx tsc --noEmit
npm run package
```

`npm start` запускает приложение для разработки. `npm run package` создаёт запускаемую сборку в `out/`, не устанавливая её в систему.

## Локальные данные

Настройки, чаты, проекты, черновики и инструкции хранятся в каталоге Electron `app.getPath('userData')` — в Windows внутри `%APPDATA%\GigaChat Agents`. `GIGACHAT.md` и проектные `AGENTS.md` остаются в данных приложения и не записываются в выбранные рабочие папки. Секреты не хранятся.

До подключения API работают локальные чаты и черновики, проекты, архив, выбор папки и программы открытия, инструкции, а также темы Изумрудная / Тёмная / Светлая / Тёплая и режим «Как в Windows». Изумрудная — тема новой установки; прежняя сохранённая «Тёмная» переносится в «Изумрудную» без изменения вида. Режим Windows использует нейтральную тёмную тему при тёмном оформлении системы. Темы, переключатели и инструкции сохраняются автоматически; при ошибке записи введённый текст остаётся в редакторе. Настройки занимают всю рабочую область. На остальных экранах панель можно полностью скрыть, временно показать наведением на кнопку и закрепить нажатием. Окно запускается размером до 960×720 со 100% масштабом содержимого; Ctrl+`+` / Ctrl+`−` меняют масштаб, Ctrl+`0` возвращает 100%. При узкой области навигация открывается поверх основного экрана. Нативные кнопки окна сохраняют размер.

Переключатель вверху боковой панели показывает GigaChat API или GigaChat Web только в текущем сеансе. Подключение Web появится позже; выбор пока не меняет возможности приложения. Значок окна и сборки создан из `src/assets/gigachat-logo.png` без изменения формы логотипа.

Сообщения не отправляются. Данные моделей, разрешений, инструментов, голоса и API показываются как недоступные; изображение сохраняется как локальный черновик, видео и подкасты отмечены как будущие функции.
